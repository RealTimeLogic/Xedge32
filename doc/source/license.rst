License
=======

Xedge32 is built on top of components from the `Barracuda App Server
amalgamated C code library <https://github.com/RealTimeLogic/BAS>`_. That
library is available under multiple licensing options, including `GPLv2, a free
commercial license, and a standard royalty-free commercial license
<https://github.com/RealTimeLogic/BAS#license>`_.

The ESP32-specific south bridge implementation for Xedge32 is available in the
`Xedge32 source repository <https://github.com/RealTimeLogic/Xedge32>`_ and is
licensed under the permissive MIT license.

If you plan to embed Xedge32 in a commercial product, review both the Barracuda
App Server licensing terms and the Xedge32 repository licensing details so your
deployment model matches the correct license option.
